# Independent taskbar per monitor

[![Windhawk catalog](https://img.shields.io/badge/Windhawk-catalog-2ea44f)](https://windhawk.net/mods/taskbar-independent-per-monitor)
![Version](https://img.shields.io/badge/version-1.7.2-blue)
![Windows](https://img.shields.io/badge/Windows-10%20%7C%2011-0078d4)
[![License: MIT](https://img.shields.io/badge/license-MIT-lightgrey)](LICENSE)

A [Windhawk](https://windhawk.net) mod: **each taskbar behaves like its own main taskbar.**

| Without the mod | With the mod |
|:---:|:---:|
| ![Without the mod](images/without-mod.gif) | ![With the mod](images/with-mod.gif) |

The pictures show: pinned items only, windows grouped and ungrouped, with and without labels,
dragging a window to another monitor and pinning an app.

## Features

* Each taskbar shows only the windows of its own monitor.
* Pin/unpin from the jump list applies to that taskbar only.
* Pin *Properties* can differ per taskbar.
* Clicking the pin of a running app brings its window to the front (Shift+click or middle-click
  starts a new instance).
* Each taskbar keeps its own order of buttons, also after a restart. New windows are added at the end.
* Drag a pin to another taskbar to move it there.
* Settings in English, German, Russian, French and Spanish.

## Install

In Windhawk, search for **Independent taskbar per monitor** and click *Install*,
or open the [catalog page](https://windhawk.net/mods/taskbar-independent-per-monitor).

Requires 64-bit Windows 10 or Windows 11 and *Show my taskbar on all displays*.
Tested with *Combine taskbar buttons: Never*.

## Settings

| Section | Setting | Default |
|---|---|---|
| Windows | Which windows each taskbar shows | Only the windows of its own monitor |
| Windows | Programs on all taskbars | none |
| Pins | Mode | Separate for each taskbar |
| Pins | Pins without an assigned taskbar | Primary taskbar only |
| Pins | Show apps on all taskbars | on |
| Click | Bring running apps to the front | on |
| Click | Windows that are brought to the front | Windows on any monitor |
| Click | Open apps on the clicked taskbar's monitor | on |
| Animation | Slide when a window moves to another monitor (Windows 11) | on |

## Compatibility

Other mods that change the taskbar buttons may get in the way. Please check the combination
yourself, there is no guarantee.

With *Disable grouping on the taskbar*, pinning from a window button pins the app's Start menu
shortcut. This is a temporary workaround for
[a bug in that mod](https://github.com/ramensoftware/windhawk-mods/issues/7900); existing pins are
not changed.

Chaque barre des tâches se comporte comme sa propre barre principale.

Les images montrent : éléments épinglés seuls, fenêtres regroupées ou séparées,

* Chaque barre des tâches n'affiche que les fenêtres de son propre écran.

* Les *Propriétés* d'un élément épinglé peuvent différer selon la barre.
* Un clic sur l'élément épinglé d'une application en cours ramène sa fenêtre au

  Les nouvelles fenêtres sont ajoutées à la fin.
* Faites glisser un élément épinglé vers une autre barre pour l'y déplacer.

Nécessite Windows 10 ou Windows 11 64 bits et *Afficher ma barre des tâches sur
tous les écrans*. Testé avec *Combiner les boutons de la barre des tâches :
Jamais*.

Remarque : d'autres mods qui modifient les boutons de la barre des tâches peuvent
gêner. Vérifiez la combinaison vous-même, sans garantie.

Avec *Disable grouping on the taskbar*, épingler depuis le bouton d'une fenêtre épingle

Cada barra de tareas funciona como su propia barra principal.

Las imágenes muestran: solo elementos anclados, ventanas agrupadas y separadas,

Nota: otros mods que cambian los botones de la barra de tareas pueden interferir.
Comprueba la combinación tú mismo, sin garantía.

Con *Disable grouping on the taskbar*, anclar desde el botón de una ventana ancla el
acceso directo del menú Inicio de la aplicación. Es una solución temporal para
